# 🌐 BBKitchen Storefront (Public Web & Catalog)

> **Public Storefront, Next.js 15 Web, Dynamic Product Catalog, WhatsApp Direct Checkout & Enterprise SEO Suite.**

---

## 🛠️ Tech Stack & Engineering
- **Framework:** Next.js 15 (App Router, Turbopack, React 19)
- **Styling:** Tailwind CSS, Radix UI, Lucide Icons
- **Data Fetching:** Hybrid SSR & ISR via API proxy to Control Tower / WordPress
- **Checkout:** WhatsApp Direct Order Engine with pre-filled SKU & pricing payload

---

## 🚀 Getting Started (Development)
```bash
# Install dependencies
npm install

# Run local development server
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.
