# BBKitchen Guides

Guides are **reference documents for humans**. They explain how the project works, where files live, and what is safe to change.

They are not execution prompts.

## Guides

- [Copy Editing Guide](COPY-EDITING-GUIDE.md) — technical map for finding and changing copy safely.
- [Vibe Coding Copy Guide](VIBE-CODING-COPY-GUIDE.md) — simplified guide for non-developers / vibe coding.

## Guides vs Prompts

```text
GUIDE
→ explains
→ maps
→ teaches
→ reference material
→ human reads it

PROMPT
→ instructs an AI session
→ defines a workflow
→ produces an action/result
→ execution protocol
```

For AI session workflows, use [`../prompts/`](../prompts/).
